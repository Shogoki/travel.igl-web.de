# Route map data

Data for the map on [/unsere-route/](https://travel.igl-web.de/unsere-route/),
generated by `scripts/route-to-yaml.py` on `main` from the list in
`content/unsere-route.md`. See "Route map" in `main`'s `CLAUDE.md`.

- `route.yaml` — the trips and their stops. Generated; don't edit it.
- `places.yaml` — the geocoding cache. Correct a misplaced point's
  `lat`/`lon` here.

This branch is separate from `main` so that the deploy workflow can commit
the regenerated data without anyone having to pull afterwards. Nothing here
deploys on its own: a push to this branch shows up on the site with the next
deploy of `main` (or run the workflow by hand under Actions → github pages →
Run workflow).

Locally, check it out next to `main` as a worktree; Hugo and the script both
read it from there:

```bash
git worktree add route-data route-data
```
